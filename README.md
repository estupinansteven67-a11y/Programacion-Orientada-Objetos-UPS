Sistema de Gestión Audiovisual - POO
Objetivos y Propósito del Proyecto
El objetivo de este proyecto es implementar un sistema funcional en Java que aplique los conceptos fundamentales de la Programación Orientada a Objetos, como la herencia y el polimorfismo, para gestionar diferentes tipos de contenidos multimedia.

Clases y Funcionalidades Nuevas
Además de las clases base (Película, Serie, Documental), he añadido las siguientes extensiones personalizadas:

VideoYouTube: Clase diseñada para gestionar contenido digital, inspirada en mi emprendimiento Neblina Custom Riders.

Cortometraje: Clase que permite registrar producciones de corta duración, con temática basada en la ciudad de Puyo.

Instrucciones para Clonar y Ejecutar
Clona este repositorio: git clone [https://github.com/estupinansteven67-a11y/Programacion-Orientada-Objetos-UPS.git]

Importa el proyecto en un IDE como Eclipse.

Ejecuta la clase PruebaAudioVisual.java ubicada en el paquete uni1a para ver los resultados en consola.

Mejoras Adicionales
Optimización de Código: Se implementó un arreglo polimórfico de tamaño 5 y un bucle para automatizar la visualización de datos de todos los objetos de forma eficiente.
